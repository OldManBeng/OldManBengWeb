## 一、色板（CSS 变量 · 舒适圈作用域）

```css
.comfort-site {
  /* ── 现行保留（实测达标）────────────────────────── */
  --ink-900: #fffdf8;   --ink-850: #fdfaf2;  --ink-800: #fbf3e4;
  --ink-700: #f4e8d2;   --ink-600: #e8d6b8;  --ink-500: #c9ae85;
  --moon: #4a3517;      --moon-dim: #6e5632;
  --amber: #b85a0a;     --amber-bright: #d97b1f;
  --ember: #b3485c;
  --text: #43331f;      --text-dim: #77613f;
  --line: rgba(95, 74, 42, 0.16);
  --line-strong: rgba(95, 74, 42, 0.3);

  /* ── 变更（诊断 V1：#a08b66 → 加深至全底达标）────── */
  --text-faint: #7e6a45;      /* 旧 #a08b66；on 纸 5.12 / 卡 4.75 / 页脚 4.72 ✅ */

  /* ── 新增令牌（收敛散落硬编码）───────────────────── */
  --amber-strong: #9a4e0b;    /* 卡底/淡橙底上的小字强调（与游戏 --c-accent-strong 同源）*/
  --rose-ink: #8f2f43;        /* 玫红系文字统一色（现散落 4 处硬编码）*/
  --phone-work: #2e6da4;      /* 「工作手机」冷色指涉统一色（切机钮/对照卡/表头标签）*/
}
```

**令牌用法规则**
1. `--text-faint` 禁止置于气泡底（#F4E8D2）——气泡内小字一律 `--text-dim`。
2. 卡片渐变底 / 淡橙底上的 11–12px 小字强调，用 `--amber-strong`，不用 `--amber`。
3. 新增样式禁止裸写色值；现存散落值（#8f2f43 ×4、#2e6da4 ×2）在第 4 阶段收敛为上述令牌。
4. 语义色备用（引游戏暖主题，本站暂未用到）：`--c-success #2f7d46` / `--c-warning #9a6b08` / `--c-danger #b3382c`。

## 三、间距与栅格（8pt 体系）

- 刻度：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 56 / 72（px）。禁用裸值如 18/22 之外的奇数（现 18/22 为历史值，保留不追改，新样式一律取刻度）。
- 区块留白：`padding: clamp(56px, 9vw, 110px) 0`（现行）。
- 卡片内边距：20–22px；网格 gap：14–20px（现行）。
- 区块留白规则：眉标 → 标题 18px；标题 → lead 14px；lead → kicker 22px；kicker → 内容 36px。
