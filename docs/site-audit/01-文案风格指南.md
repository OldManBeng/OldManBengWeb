## 一、品牌语调（5 个关键词）

### 1. 温暖而不甜腻
家常的温度靠具体的事，不靠感叹号和形容词。
- ✅ 正例：`锅里给你留了排骨汤，回老家那天，妈给你盛最稠的。`
- ❌ 反例：`妈妈的爱是最伟大的港湾！快来感受这份温暖吧！`

### 2. 账本体
这个家的情感语言就是记账：一切都可以记一笔——数字是冷的，人事是暖的，放在一起才成立。
- ✅ 正例：`账本上他最后一笔记的还是运费：四百二，说给你买件冬衣。`
- ❌ 反例：`父爱如山，他用生命诠释了责任二字。`

### 3. 素颜真实
不夸大、不营销腔。禁止"震撼""顶级""沉浸式""匠心"一类通用赞美词；说事实，让事实自己重。
- ✅ 正例：`她的钱往你这儿流，不要利息，不要话术，不要你演任何人。`
- ❌ 反例：`沉浸式体验母女情深，感受直击灵魂的震撼剧情！`

### 4. 口语家常
短句，北方口语点缀可以有一两处（吃了没 / 稳得很），但不出戏、不堆砌。
- ✅ 正例：`这边的人问"吃了吗"，问完了不会给你转 520——他们只是想知道你吃没吃。`
- ❌ 反例：`此处存在着深入的关怀式问询机制。`

### 5. 哀而不伤
刀在细节里，不喊出来。判词让位给事实，不使用情绪绑架句式（"你一定会哭"）。
- ✅ 正例：`通报没写名字。但配图里那件灰卫衣，和门把手上挂了好几天的裙子，是一套。`
- ❌ 反例：`看到这里你一定会泪流满面，这是全游戏最虐的一幕！`

## 二、术语表

| 术语 | 统一写法 | 规则 |
|---|---|---|
| 产品总名 | 情感反诈模拟器 | 不用引号不加书名号 |
| 本站名 | 舒适圈 | 大标题/品牌位用；不写"舒适圈版本" |
| 冷色侧 | 工作手机 | 与"五个「哥哥」"绑定出现时可用原称 |
| 暖色侧 | 常用手机 | 不写"日常手机/生活号" |
| 内容线 | 暗线 | 首现可作"暗线「舒适圈」"，后文只写暗线 |
| 小说/剧情全文 | 《家的账本》 | 一律带书名号 |
| 联系时间 | 联系时间（每天 40 分钟，每场 10 分钟） | 首现带括注，后文只写"联系时间"；不写"40 分钟联系时间"混排 |
| 日历剧情卡 | 剧情卡 | 首现"日历剧情卡"，后文"剧情卡"；共 11 张，写"11 张" |
| 突发事件 | 突发事件 | 共 10 件，写"10 件"；不用"随机事件" |
| 每日经文 | 经文 | 不写"圣经原文/金句" |
| 剧情天 | D2、D9、D30 | 大写 D + 半角数字，无空格；正文叙述写"第 N 天" |
| 角色 | 妈（王秀兰）、阿凯、凤霞姨（刘凤霞）、曼曼（沈曼）、爸（老周）、兰姨、小满 | 正文用惯称；括注本名仅首现 |
| 切机按钮 | 冷侧「⇄ 切换常用手机」／暖侧「⇄ 切回工作手机」 | 固定文案，不改写 |
| 版本号 | v1.1 | 小写 v；不写 V1.1 / 1.1版本 |
| 数字与中文之间 | 40 分钟、11 张、10 件 | 半角数字 + 空格；金额 520、1500 不加"元"也可，全站统一加"块/元"择一（现用"块"口语、"元"叙述，保持） |

**引号体系（对应诊断 V7）**：
- 界面叙述、标题、强调 → 直角引号「」；
- 角色原话的直录引文 → 保留原文弯引号 "……"（游戏数据原样，不改写台词）；
- 书名、篇名 → 《》。
- 判别法：句子是"官网在说话"用「」；句子是"角色被引用"用 " "。

## 三、句式规范

1. 主标题 ≤ 12 字且说清价值（现全站达标：`常用手机，暖色的那部` / `四十分钟，怎么花` / `只交代来路`）。
2. 每个区块只讲 1 个核心信息；lead ≤ 2 句。
3. 按钮动词开头：`阅读暗线《家的账本》` `从第一章开始` `进入游戏`；次级按钮可用名词短语但 ≤ 8 字（`了解这条暗线`）。
4. 卡片描述 ≤ 3 行（约 60 字）；超出即拆或删。
5. 数字一律半角 + `tabular-nums`。
6. **重复控制**：同一金句/句式全站最多出现 2 次（对应诊断 C1/C2）。
7. 内部语汇不出站（对应诊断 C4）：审计口径、零重复、代码字段名等只出现在开发文档，不出现在访客可见文案。
