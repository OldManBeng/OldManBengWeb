### 回归中发现并修复的问题：锚点定位时序缺陷

**现象**：带锚点直链/刷新、跨站点 hash 切换时，锚点偶发不定位或漂移（`#endings` 停在 9633px 等）。

**根因**（插桩 trace 确认）：原实现 `scrollIntoView({behavior:'auto'})` 继承全局 `scroll-behavior:smooth`，与浏览器原生锚点滚动竞争；单次 rAF 定位在「display=swap 字体晚到布局漂移」「rAF 被节流延迟数秒」两类场景下失效。

**修复**（`src/App.tsx`）：先以同位 instant 滚动打断原生动画；rAF / 400ms / 1200ms / `document.fonts.ready` 四时点 instant 校准；用户一旦滚轮/触屏主动滚动即停止全部校准。修复后四条路径（直链深锚 ×2、站内跳转、跨站切换）全部精确到位（top=68 = scroll-margin 预期值）。
